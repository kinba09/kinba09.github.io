SpotDiff Eval

An open visual reasoning development benchmark with deterministic scoring.

I created a benchmark and evaluation harness for models asked to identify visible differences between two image panels. The development set contains 10 composite images and 61 annotated differences.

What is measured

A model receives the full composite image and returns differences as structured JSON. Ground-truth annotation files stay out of model payloads; the local scorer uses them afterward.

Scoring design

Predictions are matched one-to-one to gold labels using deterministic rules. The report exposes precision, recall, attribute accuracy, coverage, missed differences, and extra predictions.

overall score = 0.60 × recall
              + 0.25 × precision
              + 0.15 × attribute accuracy

Coverage is reported separately. Weak subject matches count as extra predictions, rather than being accepted as correct.

Results and validation

I evaluated seven vision models end-to-end and smoke-tested eight more. In one reported run, Gemini 3.1 Flash scored 32.8% overall, with 57.1% precision and 19.7% recall. These are results on this development set, not general estimates of visual reasoning ability.

The harness includes 19 automated tests and a perfect-prediction fixture expected to score 100%, providing a regression check for the scorer and annotations.

Inspect the benchmark

After installing the repository package, reproduce the perfect baseline from the checkout:

spotdiff evaluate \
  --manifest data/manifest.json \
  --predictions predictions/perfect.json

Limitations

This is a small, public development benchmark. The images, annotations, and scoring rules are inspectable; community leaderboard results are self-reported. It is not a hidden test set or an independently verified ranking.
