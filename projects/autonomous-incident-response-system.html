Autonomous Incident Response System

Basic incident simulator that generates service behavior, structured JSON logs, and alert events for future agent workflows.

Technical Highlights

  • Mocks auth, payments, and orders service behavior with intentionally elevated payment failures.
  • Writes structured application logs to JSONL files for downstream analysis.
  • Emits alert events when rolling-window 5xx error rate crosses a configurable threshold.
  • Supports local Python execution and Docker Compose for OS-independent setup.
  • Designed as a simple base for plugging in LangChain or agent-based incident workflows.

Stack

Python, Docker, Docker Compose, structured JSON logs, alert thresholds, and configurable simulator settings.
