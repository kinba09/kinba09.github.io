GitHub Jira Sync

Dockerized backend that connects GitHub pull request events to Jira comments and Slack mismatch alerts.

Technical Highlights

  • Handles GitHub PR opened/reopened webhooks and extracts Jira issue keys from branch names.
  • Uses Arcade tools to fetch PR details, add deduplicated Jira comments, inspect Jira state, and send Slack messages.
  • Runs delayed consistency checks when PRs or Jira issues change state.
  • Loads YAML policy-as-code rules for alert conditions and message templates.
  • Supports tenant self-onboarding APIs for multi-user GitHub, Jira, Slack, and Arcade routing.

Stack

Docker, GitHub webhooks, Jira webhooks, Slack alerts, Arcade tools, YAML policies, tenant config, and local persisted state.
