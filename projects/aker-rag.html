Aker RAG

A property-specific AI assistant combining deterministic SQL, retrieval, LLM routing, property scoping, and rich UI outputs.

Technical Highlights

  • Structured MySQL queries over rent roll data.
  • Unstructured retrieval over scraped company and property context.
  • Runtime LLM switching for experimentation and fallback behavior.
  • Guardrails for property-level scoping and answer boundaries.
  • Markdown, table, and KPI-style rendering for clearer responses.

Stack

Python, SQL, RAG pipelines, Vector DBs, LLM APIs, and a structured UI response layer.
