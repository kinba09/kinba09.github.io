AffectKit

Emotion-state middleware for LLM agents that simulates affective state as a controlled behavior-modulation layer.

  • Loads YAML emotion profiles and maintains bounded affective state across turns.
  • Applies mood decay, emotional memory, and deterministic state updates from interaction events.
  • Wraps plain Python callables, LangChain-style agents, and LangGraph-style nodes.
